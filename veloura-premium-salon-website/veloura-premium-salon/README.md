# VELOURA — Premium Salon Website Demo

A responsive, animated multi-section salon website concept built with plain HTML, CSS and JavaScript. Designed to be easy to customize in VS Code and deploy on Vercel.

## Run locally
1. Extract the project folder.
2. Open `index.html` in a browser, or open the folder in VS Code and use Live Server.

## Deploy to Vercel
1. Upload/push this folder to a GitHub repository.
2. Import the repository in Vercel.
3. Use the project root as the root directory. No build command is needed; this is a static site.

## Before using for a real salon
- Replace the fictional brand name “Veloura”, logo mark, team names, location, hours and phone number.
- Replace the demo testimonial with a real, permissioned client review or remove it.
- Update services and prices after the salon approves them.
- Connect the booking form to WhatsApp, email, a CRM, or a real booking provider. Currently it is a front-end demo and does not submit or store appointments.
- Replace the social link placeholder with the salon's actual profile.
- Images are loaded from Unsplash via remote URLs; ensure the selected images fit the salon brand and review image usage/licensing before commercial launch. A live internet connection is needed to load remote images and Google Fonts.
- Add a privacy notice if you collect customer information, and test all links/forms on real devices before launch.
